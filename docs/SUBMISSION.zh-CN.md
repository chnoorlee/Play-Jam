# 《余信 / THE LAST POST》参赛交接说明

版本日期：2026-11-21。当前为本地可玩 Demo 与交接材料，尚未报名或提交；团队、正式主题与提交要求仍待确认。

## 作品简介

在一座即将被潮水淹没的邮政小岛，许渡带着母亲的旧邮包，于最后一夜投递三封未达之信。钟楼的道歉、温室的种子与站台的等待，被留在“此刻”和“回声”的两面时间里。玩家通过寻找线索、修复机关与决定信件的去向，让三个收件人说完未尽之言，最后决定自己与邮局的关系。

一句话提案：**切换此刻与回声，送完三封未达之信，再决定记忆该留在原地，还是随人远行。**

作品类型：中文、单人、2.5D 叙事解谜；Three.js 浏览器游戏。当前范围是一座紧凑岛屿、三条投递支线、每条支线的选择，以及“放流、守灯、携信”三个终局。支线选择改变人物回应与结局回顾；最终结局由玩家主动选择，没有隐藏的善恶计分。

## 运行与试玩

发行构建在 `dist/`；从 GitHub 克隆源码后，先运行 `npm ci` 与 `npm run build` 生成该目录。本地启动脚本为项目根目录的 `start.cmd`。安装 Node.js 22.12+ 并完成构建后运行该脚本，保持窗口开启，在浏览器打开窗口打印的本地地址。默认端口为 4173；端口被占用时，以实际打印地址为准。请使用支持 WebGL 的现代浏览器。

完整构建可由本地 HTTP 服务加载；游戏过程不依赖在线大模型、外部素材 CDN 或其他公网服务。首次安装开发依赖与运行已构建游戏是不同步骤。

点击地面移动、点击场景物体前往互动；界面提供时态切换、投递手记、声音和暂停按钮。`Q` 切换此刻/回声，`J` 打开手记，`Esc` 关闭对话或打开暂停。浏览器允许本地存储时自动保存投递进度；存档只在当前浏览器与地址下保留，不是云存档。重新开始会清空当前旅程，界面设有确认。

结局后可选“回到最后一夜”重新作出终局选择，也可导出当前结局与人物回顾的文本。改变已完成的支线决定需重新开始。

## 演示路径（含谜底）

1. 与邮局前的沈伯交谈，接过邮包。
2. 读钟楼脚下的家书；在“此刻”按离港、熄灯、归家设置刻度 `III / I / II`，即 `3 / 1 / 2`。完成机关后选择补全道歉或保留空白。
3. 读温室旁的种植手记；进入“回声”，把晨光、午光、暮光设为东、南、西，即内部值 `[1, 2, 3]`。完成后选择种子的去处。
4. 在旧站台的“此刻”和“回声”分别收集半枚邮戳，开启站台信箱，再为阿岚作出选择。三条支线可以按不同顺序完成。
5. 三封信投递完成后回邮局查看最后的灯，选择放流、守灯或携信，阅读终局与三段人物回顾。
