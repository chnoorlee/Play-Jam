# 《余信 / THE LAST POST》AI 与素材披露

更新日期：2026-11-23。

## 水粉美术与南岸邮路

南岸邮路的芦苇渡口、盐田和青岬气象台由 Codex 编写绘图脚本生成。脚本用分层色块、笔触和纸纹绘制建筑、芦苇、盐池与山脊等地物，输出三张供游戏加载的 WebP。对应源文件是 `scripts/paint-voyage.py`。港湾的 Three.js 场景增加了颜料纹理与哑光色彩。

封面、四处室内场景、五名人物和头像保留原版网页插画的构图，使用 `scripts/paint-harbor.py` 重新处理色块、明暗边界和纸纹。下表记录原始素材来源。此次更新未通过网页 GPT Image 2 生成新图。南岸邮路的故事、双语文本、机关和回执由 Codex 辅助编写。

旧站台的搪瓷纹理 `station-enamel.webp` 从现有站台插画的铁牌表面取样。Codex 辅助编写了站牌的双语通告、时刻表与手写留言。游戏用同一份文字绘制场景中的站牌及点开后的放大画面。

## 实际 AI 使用

本作由 Codex AI 开发代理根据用户的比赛海报、叙事要求与 2.5D 偏好制作。AI 代理编写、修改和整合了剧情设定、角色、信件、对话、分支与结局，以及游戏逻辑、界面、场景、声音和测试代码；并检索公开资料、编写研究与交接说明。AI 代理参与自动化检查和代码检查，不等同人类试玩或专家评审。

| 内容 | 实际实现及 AI 参与 | 外部素材情况 |
| --- | --- | --- |
| 故事与文字 | AI 代理编写原创邮岛故事、人物文本与确定性分支；未使用已知作品的剧情文本作为游戏素材 | 参考作品用于研究，没有导入其故事文件 |
| 港湾地图 | Codex 辅助编写 Three.js 几何、材质、光照、角色和动画代码，浏览器在玩家行走时实时渲染港湾 | 地图中的建筑与行走角色由程序构建 |
| 封面和四处可调查地点 | Codex 根据剧情与调查物件编写美术提示，在 ChatGPT 网页版分别生成海港封面、白沙邮局、钟楼、玻璃温室和旧站台的原画，下载后在本地转为 WebP。结局明信片复用海港封面，浏览器 Canvas 叠加投递结果 | 游戏随包提供预生成插画 |
| 五名人物与五张对话肖像 | ChatGPT 网页版单独生成曹遥立绘，另以四人稿生成沈伯、叶青、阿岚和许渡。原画下载后在本地拆分、去背景并整理成透明立绘。每名角色各有一张取自本人原画的 256 × 256 对话头像 | 游戏随包提供预生成人物插画和裁切头像 |
| 声音 | AI 辅助编写 Web Audio 振荡器与包络等合成代码，运行时合成环境音乐与提示音 | 未使用外部音乐/音频生成工具、录制配音、购买音乐或采样包 |
| 交互与剧情执行 | AI 代理编写状态机、机关、寻路整合、分支、结局、界面和浏览器存档代码 | 使用下列开源库，不将库代码声称为本作原创 |
| 图标 | 使用 Lucide 图标，并由 AI 编写界面整合代码 | 第三方开源图标，按其许可证保留署名和声明 |

图像工具记录为 **ChatGPT 网页版图像生成**。现有记录可确认使用了网页生图功能，具体后端图像模型版本尚未核实。

钟楼与温室各有两种时间状态。“回声”沿用网页生成的原画，“此刻”在同一原画上作黎明前的冷色调处理。温室的“此刻”版本还在镜面上补绘裂纹和缺口，对应玩家切换时间后才能使用完整镜子的剧情。

## 运行方式与存档

剧情、机关答案与结局由确定性代码执行，不在游戏运行时调用 LLM 或在线生成对话。游戏资源可通过本地 HTTP 服务加载，运行不依赖公网 API 或素材服务。该陈述不表示无需本地服务器、浏览器或支持 WebGL 的设备。

允许本地存储时，进度保存在当前浏览器的 `localStorage`；三条支线决定和终局随进度保存。本作没有服务器账号或云存档。结局文本可由玩家主动导出为本地文本文件。

## 复古海港美术参考

- 用微缩手作的层次区分岸墙、栈桥和地标，用可辨识的屋顶与窗户轮廓保留俯视视角下的方向感。[Pinterest 微缩手作趋势](https://newsroom.pinterest.com/news/2026-pinterest-hobbies-trend-report/)
- 封面采用复古海滨海报的标题层级。对话、投递手记和明信片沿用邮品的边线、邮戳与留白。[Pinterest 海滨字体指南](https://guide.pinterest.com/design/beach-canva-fonts/) · [Pinterest 信封设计指南](https://guide.pinterest.com/diy-and-crafts/creative-ways-to-address-an-envelope/)

上述资料用于设计港湾轮廓和邮品界面。游戏加载本项目发布的图像文件，未嵌入 Pinterest 图片。

人物原画参考了用户提供短片中的近景眼神、发丝分组和脸部光影；服装、道具及场景按本作角色和剧情设计。短片画帧与音轨未纳入游戏。[哔哩哔哩原短片](https://www.bilibili.com/video/BV187HT68EBG/)

当前构建直接使用 `src/art/` 中提交的 WebP。仓库保留的四个 Pillow 脚本 `generate-cover.py`、`generate-scenes.py`、`generate-scene-cast.py` 和 `generate-portraits.py` 用于生成上一版程序绘制稿。运行旧脚本会覆盖对应路径下的当前美术文件，正常构建无需执行这些脚本。
