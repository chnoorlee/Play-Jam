# 演示流程（含剧透）

开始旅程，与守夜人沈伯交谈并接过邮包。三封信可自由选择顺序；按下列顺序演示可看到每种机制。

1. 点击“未寄出的信”，读完关于钟楼的家书。记住三个刻度：**3、1、2**。
2. 在“此刻”走到钟楼，将三枚刻度分别转到 3、1、2，再确认机关。接着在人物对话中作出选择，才算完成这封信。
3. 点击“园丁的手记”并阅读。切换到“回声”，前往玻璃温室，将三面镜子依次转为**东、南、西**，确认光路后选择如何安置种子。
4. 在“回声”拾取站台附近的一半邮戳；回到“此刻”拾取另一半。走到旧车站，合上两半邮戳并决定如何回应等待者。
5. 三封信全部投递后，点击邮局的灯。作出最后选择，进入相应结局；此前三个人物选择会出现在结局回信中。

结局页“回到最后一夜”可保留三封信的决定，重新选择最终结局。“留下这封信”会下载当前结局及人物回响的文本。要重新选择三个人物的决定，在暂停菜单中重新开始。

不需要按着角色穿过建筑；点击地标后会沿桥和小路自动寻路。若切换时间或开始键盘移动，当前自动行走会取消。线索均可在右上角投递手记中重读。
