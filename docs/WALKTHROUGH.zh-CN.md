# 演示流程（含剧透）

开始旅程，与守夜人沈伯交谈并接过邮包。三封信可自由选择顺序；按下列顺序演示可看到每种机制。

1. 点击“未寄出的信”，读完关于钟楼的家书并收进手记。目标刻度是**离港 III、熄灯 I、归家 II**。
2. 在“此刻”走到钟楼。铜环有联动：转“离港”会带动“熄灯”，转“熄灯”会带动“归家”，“归家”只转自己；每轮在 0–3 之间循环。**从全部为 0 的初始状态开始，依次点击“离港”3 次、“熄灯”2 次、“归家”0 次**，最终显示 3、1、2。点击“让钟重新走动”，再在人物对话中作出选择，才算完成这封信。若之前已转过，使用机关旁灯泡提示的第三张便笺，按当前状态给出的次数操作。
3. 点击“园丁的手记”并阅读。切换到“回声”，前往玻璃温室，将三面镜子依次转为**晨光向东、午光向南、暮光向西**；从初始的北、北、北分别点击 1、2、3 次。图中光要从源头连续经过三面镜子直到种子，前段断开时后段不会独立亮起。确认光路，再选择种子的去处。
4. 进入旧站台，点开旧站牌。读“此刻”的邮务通告，在“回声”里读同一位置的行车时刻与小川的留言，两次调查的先后顺序不限。分别记下所见，再打开转寄信箱。通告说明北站永久停收，时刻表和留言把信引向南岸的约定。转寄单依次填**北站 → 停运 → 南岸 → 重逢**（`north → closed → south → reunion`）。填错可以回站牌核对或重新排列，手记中的记录会保留。最后读信，决定怎样回应阿岚的等待。
5. 每次人物选择后都会得到一份回执与纪念物；打开投递手记的“回信”页可以重读。“投递”页显示已送达与仍未完成的地址。
6. 三封信全部投递后，点击邮局的灯。作出最后选择，进入相应结局；此前三个人物选择会出现在人物回响与纪念物中。

结局页“回到最后一夜”可保留三封信的决定，重新选择最终结局。“留下这封信”下载结局、人物回响与三份回执的文本；“收藏夜航明信片”下载当前结局及人物回响的 PNG 图片，两种文件都包含 AI 辅助披露。要重新选择三个人物的决定，在暂停菜单中确认重新开始；建议先在设置中备份 JSON 投递记录。

不需要按着角色穿过建筑；点击地标后会沿桥和小路自动寻路。若切换时间或开始键盘移动，当前自动行走会取消。线索均可在右上角投递手记中重读。

需要更清楚地观察时可使用放大与全景图标；阅读困难可在设置中启用“大号文字”。机关的三层提示不会自动改变机关值或完成投递。

## 南岸邮路（含解答）

在任一结局页选择“出发 · 南岸邮路”。每站先查两处记录，再操作第三处设施。每封信的收件人由玩家决定。

1. 芦苇渡口。看系船棚的行船规矩，再调查潮尺。在清早拓印上点第三格，在此刻水面上点第二格。水位下降，在绞盘选择外汊并签发开航单，渡船便会离开码头。
2. 盐田。读过盐棚和水闸的记录，在装箱台选择二斤和五斤，两枚砝码凑出七斤。核秤后为另一联收据选去处。
3. 青岬气象台。在旗杆旁读灯号表，到值班室查三个地名，在信号灯台输入“短、长、短”。选择山脚住户，窗户会依次亮起；选择归航码头，最后一艘渡船会沿着灯光靠岸。回访时可以查看回执与自己留下的景象。
